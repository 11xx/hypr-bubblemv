#+title: bubblemv

Bubble-style directional window movement for Hyprland's Dwindle layout.

Hyprland's native directional move takes a window out of its split and drops
it next to whatever lies in that direction. Rearranging a Dwindle tree by hand
then means preselecting sides and rotating splits one step at a time.

=bubblemv= reads the focused window's Dwindle node and picks one of three
moves:

- toward its sibling in the same split: swap the two;
- across the split's orientation: rotate the split so the window lands on the
  requested side;
- past the split's outer edge: preselect the side the window came from, then
  move it out of the split, onto the next monitor if one lies that way.

The layout changes themselves go through Hyprland's Dwindle code. Floating and
fullscreen windows, and layouts other than Dwindle, get Hyprland's native
directional move.

Rotating a split needs =dwindle:preserve_split= (or =smart_split= or
=precise_mouse_move=). Without any of them Dwindle orients every split by its
shape, so a move across a split also falls back to the native move.

* Install

Requires Hyprland 0.56 or later, and the Lua 5.5 development files Hyprland
itself builds against. Plugins have no stable ABI, so rebuild after every
Hyprland update (=hyprpm update=). The repository is =hypr-bubblemv=;
the plugin is =bubblemv=.

#+begin_src sh
hyprpm add https://github.com/11xx/hypr-bubblemv
hyprpm enable bubblemv
hyprpm reload
#+end_src

Without hyprpm, =make= builds =./bubblemv.so= against the installed Hyprland
headers, or against a source checkout with =make HYPRLAND_SRC=/path/to/Hyprland=;
load it with =hyprctl plugin load "$PWD/bubblemv.so"=.

* Usage

From the Lua config, bind a closure so the move runs on key press rather than
while the config loads:

#+begin_src lua
function bubblemv(direction)
    return function()
        return hl.plugin.bubblemv.move(direction)
    end
end

bind("SUPER + SHIFT + H", bubblemv("left"))
bind("SUPER + SHIFT + J", bubblemv("down"))
bind("SUPER + SHIFT + K", bubblemv("up"))
bind("SUPER + SHIFT + L", bubblemv("right"))
#+end_src

Or from a shell: =hyprctl dispatch bubblemv up=. Directions are =left=,
=right=, =up=, =down=, the initials =l=, =r=, =u=, =d=, and =top=/=t=,
=bottom=/=b=.

A rotated split takes =dwindle:default_split_ratio=, so a wide 80/20 split
does not turn into a tall 80/20 one. To keep the old ratio instead:

#+begin_src lua
hl.config({ plugin = { bubblemv = { reset_split_ratio_on_rotate = false } } })
#+end_src
