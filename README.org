#+title: bubblemv

* Purpose

=bubblemv= adds directional bubble movement for Hyprland's native Dwindle
layout.

It is inspired by old bspwm bubble-move scripts, but it is implemented against
Hyprland v0.55+'s native layout internals. The plugin reads the active Dwindle
node, decides whether a move should swap siblings, rotate the current split, or
move out into a directional target, then delegates the actual layout changes to
Hyprland.

* Behavior

For the active tiled Dwindle window:

- Moving toward an immediate sibling swaps the active node with that sibling.
- Moving orthogonally to the current split rotates the split so the active
  window lands on the requested side. By default, that new split uses
  Hyprland's configured Dwindle split ratio instead of preserving the old
  split's ratio in the new orientation.
- Moving out of the current split edge preselects the side the window came from,
  then uses Hyprland's native directional move. When the move crosses monitors,
  the preselect is applied to the destination monitor's active workspace.

This keeps native Dwindle monitor fallback behavior for cross-monitor moves.

* Usage

For keybinds in Lua config, define a small helper so the plugin runs when the
key is pressed:

#+begin_src lua
function bubblemv(direction)
    return function()
        return hl.plugin.bubblemv.move(direction)
    end
end

bind("SUPER + SHIFT + H", bubblemv("left"))
bind("SUPER + SHIFT + J", bubblemv("down"))
bind("SUPER + SHIFT + K", bubblemv("up"))
bind("SUPER + SHIFT + L", bubblemv("right"))
#+end_src

Do not pass =hl.plugin.bubblemv.move("left")= directly to a bind helper. That
calls the plugin while the config is loading and passes the returned boolean to
the bind, not the action itself.

From a dispatcher:

#+begin_src sh
hyprctl dispatch bubblemv up
#+end_src

Accepted directions are =left=, =right=, =up=, =down=, their first-letter aliases
=l=, =r=, =u=, =d=, and the aliases =top=, =t=, =bottom=, =b=.

* Configuration

By default, when =bubblemv= rotates a split it resets that node's ratio to
Hyprland's =dwindle:default_split_ratio=. This avoids carrying a wide 80/20
horizontal split into an 80/20 vertical split.

To preserve the previous ratio on rotation:

#+begin_src lua
hl.config({
    plugin = {
        bubblemv = {
            reset_split_ratio_on_rotate = false,
        },
    },
})
#+end_src

* Notes

This plugin is intentionally Dwindle-specific. Floating windows, fullscreen
windows, non-Dwindle layouts, and unsupported states fall back to Hyprland's
native directional window move.

Hyprland plugins do not have stable ABI compatibility. Rebuild this plugin after
updating Hyprland.
