#+title: hypr-bubblemv install notes

* Install With hyprpm

After publishing this repository:

#+begin_src sh
hyprpm update
hyprpm add https://github.com/11xx/hypr-bubblemv
hyprpm enable bubblemv
hyprpm reload
#+end_src

For local testing through =hyprpm=, use a =file://= URL:

#+begin_src sh
hyprpm add file:///path/to/hypr-bubblemv
hyprpm enable bubblemv
hyprpm reload
#+end_src

If the repository is already registered, remove it before adding the local URL
again:

#+begin_src sh
hyprpm remove hypr-bubblemv
hyprpm add file:///path/to/hypr-bubblemv
#+end_src

Then call the plugin from Hyprland Lua keybinds with a small helper:

#+begin_src lua
function bubblemv(direction)
    return function()
        return hl.plugin.bubblemv.move(direction)
    end
end

bind("SUPER + SHIFT + H", bubblemv("left"))
bind("SUPER + SHIFT + J", bubblemv("down"))
bind("SUPER + SHIFT + K", bubblemv("up"))
bind("SUPER + SHIFT + L", bubblemv("right"))
#+end_src

* Local Development Install

Clone Hyprland source matching your running Hyprland build:

#+begin_src sh
git clone https://github.com/hyprwm/Hyprland /tmp/Hyprland
#+end_src

Build this plugin:

#+begin_src sh
cd /path/to/hypr-bubblemv
make HYPRLAND_SRC=/tmp/Hyprland
#+end_src

Load it for the current session:

#+begin_src sh
hyprctl plugin load "$PWD/bubblemv.so"
hyprctl plugin list
#+end_src

When using =hyprpm=, do not load the plugin with =hl.plugin.load= from the Lua
config. Let =hyprpm reload= manage load state.

* Development Dependencies

Hyprland's plugin workflow commonly needs a C++ compiler and build tools such as
=gcc=, =git=, =cmake=, =meson=, and =cpio=. Depending on the distro, install
development packages for Wayland, xkbcommon, pixman, libdrm, pango/cairo,
libinput, libudev, and hyprlang.

* After Hyprland Updates

Hyprland plugins must be rebuilt against the matching Hyprland version.

For =hyprpm= installs:

#+begin_src sh
hyprpm update
hyprpm reload
#+end_src

For local development builds:

#+begin_src sh
cd /path/to/hypr-bubblemv
make clean
make HYPRLAND_SRC=/tmp/Hyprland
hyprctl plugin unload "$PWD/bubblemv.so"
hyprctl plugin load "$PWD/bubblemv.so"
#+end_src

* Troubleshooting

If =hyprctl plugin load= fails, first rebuild against the exact Hyprland source
for your running compositor. If the Lua wrapper silently behaves like native
movement, check =hyprctl plugin list= and Hyprland logs for plugin load errors.

For =hyprpm= build failures, rerun the update/build with verbose output:

#+begin_src sh
hyprpm -v update
hyprpm list
#+end_src
